# Mutluet - Gönüllülük ve Sosyal Etki Platformu

![Mutluet Logo](assets/images/logo.png)

## 📱 Hakkında

Mutluet, Türkiye'deki NGO'ları ve gönüllüleri bir araya getiren mobil uygulamadır.

### Özellikler

- ✅ Gönüllülük etkinliklerine katılım
- ✅ Akıllı gönüllü eşleştirme
- ✅ Güvenli bağış yapma (Stripe)
- ✅ Oyunlaştırma (rozetler, liderlik tablosu)
- ✅ Video görüşme (Azure Communication Services)
- ✅ Real-time mesajlaşma
- ✅ Google Maps entegrasyonu

## 🛠️ Teknolojiler

- **Frontend:** Flutter 3.16
- **Backend:** Node.js + Express (Azure App Service)
- **Database:** Azure PostgreSQL / MongoDB
- **Authentication:** JWT + OAuth (Google, Facebook)
- **Payments:** Stripe
- **Maps:** Google Maps API
- **Real-time:** Socket.IO
- **Storage:** Azure Blob Storage
- **Analytics:** Firebase Analytics + Sentry

## 🚀 Kurulum

```bash
# Repository'yi klonla
git clone https://github.com/omerfarukkural/mutluet-app.git
cd mutluet-app

# Dependencies yükle
flutter pub get

# Çalıştır
flutter run
```
